# Project6_FashionMN

## Español
> En este proyecto utilicé una red neuronal convolucional o CNN para clasificar el set de datos "fashion MNIST" que contiene 60,000 imagenes de ropa en escala de grises de 28x28 píxeles.

## English
> For this project i'm using a CNN (Convolutional Neural Network) to classify the "Fashion MNIST" dataset, this dataset contains 60,000 clothe images in gray scale of 28x28 pixels size.


## Descripción / Description
> Este proyecto es un poco más complejo que el anterior, es un proyecto de visión por computadora que aceleramos con torch.cuda y usamos una capa de dropout para apagar neuronas en el entrenamiento, este modelo propone poder clasificar diferentes imagenes en 10 diferentes tipos de ropa. Se utilizó PyTorch como herramienta principal y el set de datos "fashion MNIST" que viene de "dataloader" dentro de PyTorch.

> This is a litle bit more complex project than the last one, its a computer vision model accelerate by torch.cuda that had a dropout layer (turn off a part of the neurons), the model propose to classify images on 10 different types of clothes. PyTorch was used as main tool and the "Fashion MNIST" dataset using "dataloader" from PyTorch
